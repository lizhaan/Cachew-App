## Що це

Cachew — Android-застосунок для людей, які купують імпульсивно, особливо з СДУГ. Він не блокує магазини і не соромить. Він дає 10 секунд, щоб зупинитися, і план, як провести наступні 10 хвилин.

## Як це працює

1. **Пауза.** Відкриваєш обраний магазин (Amazon, Shein, Temu, Rozetka чи будь-який інший застосунок), і поверх нього з'являється кільце на 10 секунд: «Pause. Breathe.».
2. **Два питання.** Як ти зараз (втома, нудьга, стрес чи все гаразд) і чи було це у твоєму списку.
3. **План на 10 хвилин.** Можна тільки подивитися й зберегти річ замість покупки, купити щось конкретне або одразу закрити магазин. Таймер і білка Пенні в кутку екрана нагадують про час, а на 5-й хвилині Пенні питає, як справи.
4. **Список очікування.** Сподобалась річ? «Поділитися» → Cachew. Фото, назва й ціна підтягуються самі, річ чекає 24, 48 або 72 години.
5. **«Still want it?»** Коли час мине, приходить нагадування (лише вдень). Відпускаєш річ — її ціна йде в заощадження і до твоєї цілі, наприклад Tokyo $900.

**Пенні і cashews.** За кожну стриману покупку білка Пенні отримує cashews у зимовий запас і росте в рівнях: від Kit до Winter-ready. Стрік рахує дні без імпульсних покупок, а 3 сердечка на місяць дозволяють купити річ зі списку раніше без штрафу.

**Нічний щит.** У вибрані години (за замовчуванням 23:00–07:00) магазини повністю закриті: «Penny's asleep. So is the sale.».

**Приватність.** Cachew бачить лише те, *який* застосунок відкрився, і ніколи не читає вміст екрана. Усі дані зберігаються на телефоні: без акаунтів, без сервера, без реклами.

**Стек:** Kotlin, Jetpack Compose, Material 3, AccessibilityService, WorkManager, jsoup, Coil.

## Як встановити на телефон

Сторінка для завантаження: **https://lizhaan.github.io/cachew-releases/** 

1. **Завантаж** файл `.apk` за посиланням або відкрий його в Telegram.
2. **Відкрий файл.** Телефон спитає, чи можна встановлювати застосунки з цього джерела (браузера чи Telegram). Натисни «Налаштування» → увімкни «Дозволити з цього джерела» → повернись назад → «Встановити».
3. Якщо з'явиться попередження **Google Play Protect** про невідомий застосунок, натисни «Усе одно встановити». Це нормально для застосунків не з Google Play.
4. **Відкрий Cachew** і пройди знайомство з Пенні до кінця.
5. **Екран «Set up Cachew»** (одразу після вибору магазинів, а пізніше в Me) проведе через усе по кроках, на будь-якому телефоні. Кожна кнопка відкриває потрібне місце в налаштуваннях:
   1. **Дозволити обмежені налаштування** (Android 13+): у налаштуваннях Cachew **⋮** (вгорі праворуч) → «Дозволити обмежені налаштування». Без цього наступний перемикач сірий.
   2. **Спеціальні можливості:** знайди **Cachew shop pause** і увімкни.
   3. **Робота у фоні:** кнопка «Open» відкриє потрібне місце саме для твого телефона (Xiaomi, Samsung, Huawei, Oppo, Vivo…). Без цього на деяких телефонах пауза з'являється лише після того, як відкриєш Cachew.
   4. **Сповіщення:** щоб прийшло нагадування «Still want it?».

Готово: відкрий обраний магазин, і Пенні покаже паузу.

## Збірка (Windows)

```bash
gradlew.bat assembleDebug
```

```bash
gradlew.bat installDebug
```

APK лежатиме в `app/build/outputs/apk/debug/app-debug.apk`. Тести логіки (правила гри, статистика, розбір сторінок товарів):

```bash
gradlew.bat testDebugUnitTest
```

Усі числа правил (пауза 10 с, сесія 10 хв, +15/+5 cashews, пороги рівнів, нічний щит, курси валют) — в одному файлі `app/src/main/java/app/cachew/data/Rules.kt`.

### APK для людей (release)

Один раз — створити ключ підпису (питає паролі; придумай і запиши їх):

```bash
"C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v -keystore cachew-release.jks -alias cachew -keyalg RSA -keysize 2048 -validity 10000
```

Потім скопіюй `keystore.properties.example` у `keystore.properties` і впиши ті самі паролі. **Збережи `cachew-release.jks` і `keystore.properties` назавжди** (хмара + флешка): без них не вийде випустити оновлення, яке встановиться поверх старого Cachew. У git вони не потрапляють.

Кожен новий APK:

1. У `app/build.gradle.kts` збільш `cachewVersionCode` і `cachewVersionName`.
2. `gradlew.bat cachewApk` → файл `release/Cachew-<версія>.apk`.
3. Опублікуй у публічному репозиторії [cachew-releases](https://github.com/lizhaan/cachew-releases) (цей репозиторій приватний, з нього файли ніхто не завантажить). Додай той самий файл ще й під назвою `Cachew.apk`: на нього веде кнопка сайту, і вона завжди відкриває останній реліз.

   ```bash
   cp release/Cachew-<версія>.apk Cachew.apk
   gh release create v<версія> release/Cachew-<версія>.apk Cachew.apk --repo lizhaan/cachew-releases --title "Cachew <версія>" --notes "..."
   ```

Сайт для завантаження: https://lizhaan.github.io/cachew-releases/ (файл `index.html` у тому ж репозиторії). Сайт правити не треба: після нового релізу кнопка сама веде на нову версію.

Release- і debug-версії підписані різними ключами, тож одна не встановиться поверх іншої: спершу видали попередню (дані Cachew при цьому зникнуть).
