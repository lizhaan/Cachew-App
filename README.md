# Cachew

Android-застосунок для людей з імпульсивними покупками (особливо з СДУГ). Коли відкривається обраний магазин, Cachew показує поверх нього паузу на 10 секунд, ставить два питання і пропонує план: тільки подивитися й зберегти річ, купити щось конкретне або закрити магазин. На все є 10 хвилин. Збережена через «Поділитися» річ чекає 24/48/72 години, потім Cachew питає «Still want it?». Білка Пенні отримує за це cashews у зимовий запас і росте в рівнях.

## Як встановити на телефон

Для всіх, хто отримав файл `Cachew-1.4.apk` (посиланням або в Telegram). Комп'ютер не потрібен.

1. **Завантаж** файл `.apk` за посиланням або відкрий його в Telegram.
2. **Відкрий файл.** Телефон спитає, чи можна встановлювати застосунки з цього джерела (браузера чи Telegram). Натисни «Налаштування» → увімкни «Дозволити з цього джерела» → повернись назад → «Встановити».
3. Якщо з'явиться попередження **Google Play Protect** про невідомий застосунок, натисни «Усе одно встановити». Це нормально для застосунків не з Google Play.
4. **Відкрий Cachew** і пройди знайомство з Пенні до кінця.
5. **Екран «Set up Cachew»** (одразу після вибору магазинів, а пізніше в Me) проведе через усе по кроках, на будь-якому телефоні. Кожна кнопка відкриває потрібне місце в налаштуваннях:
   1. **Дозволити обмежені налаштування** (Android 13+): у налаштуваннях Cachew **⋮** (вгорі праворуч) → «Дозволити обмежені налаштування». Без цього наступний перемикач сірий.
   2. **Спеціальні можливості:** знайди **Cachew shop pause** і увімкни.
   3. **Робота у фоні:** кнопка «Open» відкриє потрібне місце саме для твого телефона (Xiaomi, Samsung, Huawei, Oppo, Vivo…). Без цього на деяких телефонах пауза з'являється лише після того, як відкриєш Cachew.
   4. **Сповіщення:** щоб прийшло нагадування «Still want it?».

Готово: відкрий обраний магазин, і Пенні покаже паузу.

## Збірка (Windows)

```bash
gradlew.bat assembleDebug
```

```bash
gradlew.bat installDebug
```

APK лежатиме в `app/build/outputs/apk/debug/app-debug.apk`. Тести логіки (правила гри, статистика, розбір сторінок товарів):

```bash
gradlew.bat testDebugUnitTest
```

Усі числа правил (пауза 10 с, сесія 10 хв, +15/+5 cashews, пороги рівнів, нічний щит, курси валют) — в одному файлі `app/src/main/java/app/cachew/data/Rules.kt`.

### APK для людей (release)

Один раз — створити ключ підпису (питає паролі; придумай і запиши їх):

```bash
"C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v -keystore cachew-release.jks -alias cachew -keyalg RSA -keysize 2048 -validity 10000
```

Потім скопіюй `keystore.properties.example` у `keystore.properties` і впиши ті самі паролі. **Збережи `cachew-release.jks` і `keystore.properties` назавжди** (хмара + флешка): без них не вийде випустити оновлення, яке встановиться поверх старого Cachew. У git вони не потрапляють.

Кожен новий APK:

1. У `app/build.gradle.kts` збільш `cachewVersionCode` і `cachewVersionName`.
2. `gradlew.bat cachewApk` → файл `release/Cachew-<версія>.apk`.
3. `gh release create v<версія> release/Cachew-<версія>.apk --notes "..."`.

Release- і debug-версії підписані різними ключами, тож одна не встановиться поверх іншої: спершу видали попередню (дані Cachew при цьому зникнуть).

## Дозволи

### 1. Спеціальні можливості (без цього паузи немає)

Cachew помічає відкриття магазину через сервіс Спеціальних можливостей. Він бачить **лише назву застосунку**, що відкрився, і не читає вміст екрана. Таймер і Пенні поверх магазину малює той самий сервіс, тому окремий дозвіл «поверх інших застосунків» не потрібен.

1. Відкрий Cachew → екран **Set up Cachew** (в онбордингу або Me → Set up Cachew) → крок «Let Cachew notice shops» → **Open**.
2. У налаштуваннях знайди **Cachew shop pause** (іноді в розділі «Завантажені служби» / «Встановлені служби») і увімкни.

#### Android 13+: перемикач сірий («Обмежене налаштування»)

Android блокує Спеціальні можливості для застосунків, встановлених не з Google Play (з APK або через Android Studio). На екрані Set up Cachew це перший крок, кнопка «Open settings» веде прямо в налаштування Cachew. Вручну:

1. Налаштування → **Додатки** → **Cachew**.
2. Натисни **⋮** (три крапки вгорі праворуч) → **Allow restricted settings** / «Дозволити обмежені налаштування». Телефон може попросити PIN.
3. Повернись у Спеціальні можливості й увімкни Cachew ще раз.

Пункт «⋮» з'являється лише після першої спроби увімкнути сервіс. Тому спершу натисни на сірий перемикач, а потім іди в налаштування застосунку.

### 2. Сповіщення

Cachew питає дозвіл на сповіщення, коли вперше зберігаєш річ. Без нього нагадування «Your 48 hours are up» не прийдуть, але все інше працює: готові речі видно у вкладці Waiting list з позначкою «ready».

### 3. Робота у фоні (залежить від виробника телефона)

Деякі виробники не дають застосункам запускатися у фоні, і тоді пауза з'являється лише після того, як відкриєш Cachew. Екран **Set up Cachew** (Me → Set up Cachew) підлаштовується під телефон і має кнопку, що веде в потрібне місце:

- **Xiaomi / Redmi / POCO:** Інші дозволи → «Показувати спливаючі вікна у фоновому режимі» + **Автозапуск**.
- **Huawei / Honor:** Запуск застосунків → вимкнути «Керувати автоматично» → дозволити автозапуск, вторинний запуск і роботу у фоні.
- **Oppo / Realme / OnePlus:** автозапуск і робота у фоні.
- **Vivo / iQOO:** запуск у фоні і спливаючі вікна у фоні.
- **Samsung та інші:** зазвичай нічого не треба.

Після цього вимкни й увімкни Cachew у Спеціальних можливостях.

### Після оновлення застосунку пауза перестала працювати

Коли Cachew оновлюють (новий APK або `installDebug`), Android може зупинити його сервіс. Перемикач при цьому лишається увімкненим, а на головній з'являється «Pauses stopped after an update».

Як виправити: Спеціальні можливості → **Cachew shop pause** → вимкни → увімкни знову.

## Як перевірити

- **Пауза:** відкрий обраний магазин → кільце 10 с → 2 питання → екран рішення.
  - «Just look, save, don't buy» — магазин на 10 хв, угорі таймер, праворуч Пенні; на 5-й хвилині шторка.
  - «I need something specific» — 10 хв, за 2 хв до кінця Пенні підстрибує.
  - «Close <магазин>» — +5 cashews (не більше 3 разів на день).
  - Через 10 хв магазин закривається, наступний вхід — знову пауза.
- **Без магазину:** Me → **Try a pause (demo)**.
- **Поділитися:** у магазині «Поділитися» → Cachew → картка з фото, назвою і ціною → «Wait 48 hours» → «Nice pause.» (+15 cashews).
- **Швидке нагадування (лише debug-збірка):** на картці товару **довге натискання на «24h»** ставить 1 хвилину. Через 1 хв прийде сповіщення → «Still want it?».
- **Buy it:** коротка пауза 10 с без питань → відкривається посилання на річ → 5 хв на покупку. До кінця очікування купити можна за сердечко: Waiting list → тап по речі → «Buy it now · uses a heart».
- **Нічний щит:** Me → Night shield. У нічні години магазини повністю закриті (Пенні спить). За 2 години до початку і до кінця щита розклад можна лише подовжити, а щит — не вимкнути. Щоб перевірити, постав «from» на найближчу хвилину; пам'ятай, що після цього змінити розклад можна буде лише після кінця тестового вікна.

## Як скинути дані

- **Me → Reset demo data** — Cachew починає з першого екрана онбордингу: речі в листі очікування, cashews, стрік, сердечка, статистика й цілі обнуляються. Обрані магазини, нічний щит і час очікування лишаються.
- Повністю, разом з онбордингом: Налаштування → Додатки → Cachew → Сховище → **Очистити дані**. Після цього знову увімкни Cachew у Спеціальних можливостях.
