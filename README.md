# Cachew

Android-застосунок для людей з імпульсивними покупками (особливо з СДУГ). Коли відкривається обраний магазин, Cachew показує поверх нього паузу на 10 секунд, ставить два питання і пропонує план: тільки подивитися й зберегти річ, купити щось конкретне або закрити магазин. На все є 10 хвилин. Збережена через «Поділитися» річ чекає 24/48/72 години, потім Cachew питає «Still want it?». Білка Пенні отримує за це cashews у зимовий запас і росте в рівнях.

## Збірка (Windows)

```bash
gradlew.bat assembleDebug
```

```bash
gradlew.bat installDebug
```

APK лежатиме в `app/build/outputs/apk/debug/app-debug.apk`. Тести логіки (правила гри, статистика, розбір сторінок товарів):

```bash
gradlew.bat testDebugUnitTest
```

Усі числа правил (пауза 10 с, сесія 10 хв, +15/+5 cashews, пороги рівнів, нічний щит, курси валют) — в одному файлі `app/src/main/java/app/cachew/data/Rules.kt`.

## Дозволи

### 1. Спеціальні можливості (без цього паузи немає)

Cachew помічає відкриття магазину через сервіс Спеціальних можливостей. Він бачить **лише назву застосунку**, що відкрився, і не читає вміст екрана. Таймер і Пенні поверх магазину малює той самий сервіс, тому окремий дозвіл «поверх інших застосунків» не потрібен.

1. Відкрий Cachew → екран «Let Cachew notice when a shop opens» → **Allow access** (пізніше: Me → Pauses).
2. У налаштуваннях знайди **Cachew shop pause** (на Xiaomi: Спеціальні можливості → Завантажені служби) і увімкни.

#### Android 13+: перемикач сірий («Обмежене налаштування»)

Android блокує Спеціальні можливості для застосунків, встановлених не з Google Play (з APK або через Android Studio). Щоб зняти обмеження:

1. Налаштування → **Додатки** → **Cachew**.
2. Натисни **⋮** (три крапки вгорі праворуч) → **Allow restricted settings** / «Дозволити обмежені налаштування». Телефон може попросити PIN.
3. Повернись у Спеціальні можливості й увімкни Cachew ще раз.

Пункт «⋮» з'являється лише після першої спроби увімкнути сервіс. Тому спершу натисни на сірий перемикач, а потім іди в налаштування застосунку.

### 2. Сповіщення

Cachew питає дозвіл на сповіщення, коли вперше зберігаєш річ. Без нього нагадування «Your 48 hours are up» не прийдуть, але все інше працює: готові речі видно у вкладці Waiting list з позначкою «ready».

### 3. Xiaomi / Redmi / POCO: ще два дозволи

1. **Автозапуск** (Autostart): Налаштування → Додатки → Cachew → увімкни «Автозапуск». Без нього Xiaomi вбиває Cachew, коли змахуєш його з недавніх, і сервіс паузи більше не запускається.
2. **Спливаючі вікна у фоні**: Налаштування → Додатки → Cachew → **Інші дозволи** → «Показувати спливаючі вікна у фоновому режимі». Без нього пауза чекає, доки ти сама відкриєш Cachew.

Після цього вимкни й увімкни Cachew у Спеціальних можливостях. На головній на Xiaomi для цього є картка «Two more steps on Xiaomi» з кнопками **Autostart** і **Pop-ups**.

### Після оновлення застосунку пауза перестала працювати

Коли Cachew оновлюють (новий APK або `installDebug`), Android може зупинити його сервіс. Перемикач при цьому лишається увімкненим, а на головній з'являється «Pauses stopped after an update».

Як виправити: Спеціальні можливості → **Cachew shop pause** → вимкни → увімкни знову.

## Як перевірити

- **Пауза:** відкрий обраний магазин → кільце 10 с → 2 питання → екран рішення.
  - «Just look, save, don't buy» — магазин на 10 хв, угорі таймер, праворуч Пенні; на 5-й хвилині шторка.
  - «I need something specific» — 10 хв, за 2 хв до кінця Пенні підстрибує.
  - «Close <магазин>» — +5 cashews (не більше 3 разів на день).
  - Через 10 хв магазин закривається, наступний вхід — знову пауза.
- **Без магазину:** Me → **Try a pause (demo)**.
- **Поділитися:** у магазині «Поділитися» → Cachew → картка з фото, назвою і ціною → «Wait 48 hours» → «Nice pause.» (+15 cashews).
- **Швидке нагадування (лише debug-збірка):** на картці товару **довге натискання на «24h»** ставить 1 хвилину. Через 1 хв прийде сповіщення → «Still want it?».
- **Buy it:** коротка пауза 10 с без питань → відкривається посилання на річ → 5 хв на покупку. До кінця очікування купити можна за сердечко: Waiting list → тап по речі → «Buy it now · uses a heart».
- **Нічний щит:** Me → Night shield. У нічні години магазини повністю закриті (Пенні спить). За 2 години до початку і до кінця щита розклад можна лише подовжити, а щит — не вимкнути. Щоб перевірити, постав «from» на найближчу хвилину; пам'ятай, що після цього змінити розклад можна буде лише після кінця тестового вікна.

## Як скинути дані

- **Me → Reset demo data** — обнуляє речі в листі очікування, cashews, стрік, сердечка, статистику й цілі. Обрані магазини, нічний щит і час очікування лишаються.
- Повністю, разом з онбордингом: Налаштування → Додатки → Cachew → Сховище → **Очистити дані**. Після цього знову увімкни Cachew у Спеціальних можливостях.
