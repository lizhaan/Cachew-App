# Cachew

Android-застосунок для людей з імпульсивними покупками. Коли відкривається обраний магазин, Cachew показує поверх нього паузу на 10 секунд, ставить два питання і пропонує відкласти товар у лист очікування.

## Збірка (Windows)

```bash
gradlew.bat assembleDebug
```

```bash
gradlew.bat installDebug
```

APK лежатиме в `app/build/outputs/apk/debug/app-debug.apk`.

## Як увімкнути паузу (Спеціальні можливості)

Cachew помічає відкриття магазину через сервіс Спеціальних можливостей. Він бачить **лише назву застосунку**, що відкрився, і не читає вміст екрана.

1. Відкрий Cachew → екран «Let Cachew notice when a shop opens» → **Allow access**.
2. У налаштуваннях знайди **Cachew shop pause** (на Xiaomi: Спеціальні можливості → Завантажені служби) і увімкни.

### Android 13+: перемикач сірий («Обмежене налаштування»)

Android блокує Спеціальні можливості для застосунків, встановлених не з Google Play (з APK або через Android Studio). Щоб зняти обмеження:

1. Налаштування → **Додатки** → **Cachew**.
2. Натисни **⋮** (три крапки вгорі праворуч) → **Allow restricted settings** / «Дозволити обмежені налаштування». Телефон може попросити PIN.
3. Повернись у Спеціальні можливості й увімкни Cachew ще раз.

Пункт «⋮» з'являється лише після першої спроби увімкнути сервіс. Тому спершу натисни на сірий перемикач, а потім іди в налаштування застосунку.

### Xiaomi / Redmi / POCO: спливаючі вікна у фоні

На Xiaomi є ще один власний дозвіл. Без нього пауза не з'являється поверх магазину, а чекає, доки ти сама відкриєш Cachew.

1. Налаштування → **Додатки** → **Cachew** → **Інші дозволи** (Other permissions).
2. Увімкни **«Показувати спливаючі вікна у фоновому режимі»** (Display pop-up windows while running in the background).

У застосунку на Xiaomi для цього є картка «One more step on Xiaomi» з кнопкою **Open settings**.

## Перевірка

- **Try a pause (demo)** на головній відкриває паузу без магазину.
- Відкрий обраний магазин: має з'явитися пауза з відліком 10 с. Після «Continue to …» цей магазин не переривається 15 хвилин.
