# Cachew: ТЗ для Claude Code (новий проєкт з нуля)

## Продукт
Cachew — Android-застосунок для людей з імпульсивними покупками (особливо з СДУГ). Коли людина відкриває обраний магазин, Cachew показує поверх нього паузу на 10 секунд, ставить 2 питання і пропонує не купувати зараз, а відкласти товар у лист очікування. Через 24/48/72 год приходить нагадування (лише вдень) з питанням «Still want it?». Маскот — білка Пенні: за кожну паузу вона отримує горіхи (кешью) у свій зимовий запас.

Це демо для захисту. Під час розробки я ставлю його на свій телефон через Android Studio. **Результат — APK-файл, який будь-хто може завантажити (за посиланням з GitHub Releases або з Telegram) і встановити на свій Android-телефон як звичайний застосунок**, без Android Studio і без кабелю. Публікація в Google Play зараз НЕ мета.

## Як працюємо
- Код пишеш ти (Claude Code). Я керую, перевіряю на телефоні і пояснюю, що не так.
- Працюємо **етапами, по одному** (див. «Етапи»). На кожен етап: план у 3–6 пунктах → код → `./gradlew assembleDebug` (на Windows `gradlew.bat assembleDebug`) без помилок → короткий звіт «що зробив / як перевірити на телефоні» → коміт → push.
- Коли вимоги суперечать дизайну або щось незрозуміло, зупинись і запитай.
- Коротко пояснюй, що робить новий код: мені його захищати.

## Стек і правила коду
- Kotlin, Jetpack Compose, Material3. minSdk 26, target/compileSdk — найновіші стабільні. Kotlin DSL у Gradle, version catalog (`libs.versions.toml`).
- Package `app.cachew`.
- Навігація: `navigation-compose`. Дані: один клас-репозиторій `Store` поверх `SharedPreferences` + JSON (`org.json` або `kotlinx.serialization`). Room і DI не потрібні.
- Дозволені бібліотеки: navigation-compose, work-runtime-ktx (нагадування), coil-compose (фото товарів), jsoup (розбір сторінки товару), kotlinx-coroutines, kotlinx-serialization. Інші — спершу запитай.
- Структура пакетів: `ui/theme`, `ui/components`, `ui/screens/<екран>`, `data`, `pause`, `share`, `service`, `reminders`.
- **Тексти в інтерфейсі англійською** (ринок — США). Тримай їх у `strings.xml`. Коментарі в коді англійською.
- Репозиторій GitHub приватний. `.gitignore` для Android обов'язковий: без `build/`, `.gradle/`, `local.properties`, `.idea/`, `*.jks`, `keystore.properties`.

Якщо push просить увійти, зупинись і скажи мені: вхід я пройду сама у вікні браузера.
- Ми на Windows: збирай через `gradlew.bat`. Якщо телефон підключено (`adb devices`), після збірки став застосунок через `gradlew.bat installDebug`.

- Рекомендовані магазини, яких немає на телефоні, показуй приглушено з підписом «not installed», але дозволяй їх обрати.
- **Будь-який застосунок.** Остання плитка в сітці — «+ Other app». Вона відкриває список усіх встановлених застосунків: іконка + назва, пошук угорі, за алфавітом, без самого Cachew. Обрані застосунки додаються в сітку плитками зі справжньою іконкою, вже вибрані.

- Збережи вибір у `Store` як список package name (і рекомендовані, і довільні).
- Цей самий екран вибору відкривається з Me → «Shops with a pause» (етап 6).
- **Перевірка:** застосунок відкривається, обрані магазини (зокрема довільний застосунок через «+ Other app») зберігаються після перезапуску.

### Етап 3. Питання, рішення, сердечко, покупка без сердечка (екрани 14, 15, 17, 21, 22)
- 14: 4 плитки настрою (Tired, Bored, Stressed, Fine) + Yes/No. «Continue» активна тільки тоді, коли є обидві відповіді. Вночі текст «before tonight?» і мітка «night shield».

- 21 і 22: «Continue to <shop>» повертає в магазин (з вікном тиші), «Back to the den» відкриває Cachew.
- У `Store`: горіхи, стрік, сердечка (3 на місяць, поновлюються 1-го числа), лог пауз (час, магазин, рішення, настрій).
- **Перевірка:** пройти всі три гілки і перевірити, що лічильники змінюються.

### Етап 4. Лист очікування, «Поділитися», нагадування, «Still want it?» (екрани 16, 18, 19, 20)
**Після цього етапу пауза працює від початку до кінця.**
- `ShareActivity` з intent-filter `ACTION_SEND text/plain`, дозвіл `INTERNET`.
- Із тексту Share дістань URL. Завантаж сторінку (IO, таймаут ~6 с, мобільний User-Agent) і розбери jsoup'ом: JSON-LD `Product` (name, image, offers.price) → `og:title` / `og:image` / `product:price:amount` → `itemprop=price` / `<title>` → запасний варіант: регулярний вираз по тексту Share (`$`, `₴`, `грн`, `€`, пробіли в тисячах, кома як десятковий роздільник).
- Поки йде завантаження, показуй скелетон. Назва і ціна мають залишатися редагованими. Якщо сторінку не вдалося завантажити, тихо залишай те, що є, без помилок на екрані.
- Фото збережи у `filesDir/thumbs/<id>.jpg` і показуй через Coil. Якщо фото немає, показуй кольоровий квадрат з літерою.
- 16: картка товару, «Wait for» 24h/48h/72h (значення за замовчуванням — з налаштувань), «Wait N hours».
- Якщо Share прийшов протягом 30 хв після паузи «Add to waiting list», товар прив'язується до цієї паузи: магазин береться з паузи, горіхи вдруге не нараховуються. Сама пауза порожнього товару не створює.
- **Нагадування (18):** WorkManager, unique work з id товару, на момент `addedAt + N год`. **Тихі години:** якщо цей момент припадає на вікно нічного щита (або на 22:00–09:00, коли щит вимкнено), перенеси нагадування на кінець вікна. Текст: «Your 48 hours are up» / «Still want the $64 knit sweater? Penny waited till morning to ask.» (останнє речення — лише якщо нагадування переносили). Канал `reminders`, іконка `cashew`. Дозвіл `POST_NOTIFICATIONS` запитуй під час першого додавання товару; якщо людина відмовила, нічого не ламається.
- Натискання на сповіщення відкриває 19 для цього товару.
- 19: **Let it go · keep $X** (статус kept, сума додається до «зекономлено») → 20; **Buy it with a heart** (−1 сердечко); **Wait another day** (+24 год, нове нагадування).
- 20: «+$64», Пенні `lie` на купці кешью, «Penny levelled up» / «stash grew», 3 статистики, «Share my win» (системний Share з текстом).
- Для тестів у debug-збірці: довге натискання на «24h» ставить 1 хвилину.
- **Перевірка:** Share з Rozetka → картка з фото і ціною → 1 хв → сповіщення → Let it go → +$.

### Етап 5. Нічний щит (екран 10)
- Час «from» і «to» обирається через Material3 `TimePicker` (24 год). За замовчуванням 23:00 → 07:00. Вікно через північ має працювати. Однакові «from» і «to» не дозволяй.
- Перемикач «Night shield on», режими Soft · daytime / Strict · at night.
- Вночі (за розкладом): нічний фон, нічні тексти на паузі, у Strict немає «Buy it anyway» і є підпис «no "buy anyway" until <to>».
- Розклад визначає і тихі години нагадувань (етап 4).
- Скрізь, де видно час щита (головна, Me, пауза), показуй реальні значення.
- **Перевірка:** ставлю щит на найближчу годину, Strict → відкриваю магазин → нічна пауза без «Buy it anyway».
- **Після етапу: запис демо з телефона** (див. сценарій нижче).

### Етап 8. APK для людей
- Налаштуй підпис release-збірки. Keystore (`cachew-release.jks`) і паролі зберігай поза репозиторієм: у `keystore.properties` у корені, і він у `.gitignore`. Згенеруй keystore командою `keytool`, а паролі попроси в мене. Поясни мені, що keystore і паролі треба зберегти: без них не вийде випустити оновлення, яке встановиться поверх старої версії.
- `gradlew.bat assembleRelease` → `app/build/outputs/apk/release/app-release.apk`. Перейменуй у `Cachew-<versionName>.apk`, наприклад через `applicationVariants` / `outputFileName`.
- Перед кожним новим APK збільшуй `versionCode` і `versionName`, інакше телефон не оновить застосунок поверх старого.
- Мінімізацію (R8) не вмикай, або перевір, що з нею нічого не ламається: Accessibility-сервіс, Share і WorkManager.
- Опублікуй APK у **GitHub Releases** (`gh release create v<версія> Cachew-<версія>.apk --notes "..."`). Покажи мені посилання на завантаження.
- Додай у README розділ **«Як встановити на телефон»** простою мовою для людей без технічних знань:
  1. Завантажити `.apk` з посилання.
  2. Відкрити файл і дозволити встановлення з цього джерела (браузера або Telegram), коли телефон попросить.
  3. Відкрити Cachew і пройти онбординг.
  4. Увімкнути Cachew у Спеціальних можливостях. **На Android 13+ для застосунків, встановлених з APK, перемикач спершу сірий («Обмежене налаштування»):** Налаштування → Додатки → Cachew → ⋮ → «Дозволити обмежені налаштування», потім увімкнути ще раз.
  5. Дозволити сповіщення.
  6. Якщо Google Play Protect попереджає про невідомий застосунок, натиснути «Усе одно встановити». Це нормально для застосунків не з Play.
- **Перевірка:** видалити debug-версію з телефона, встановити APK, завантажений за посиланням, і пройти сценарій демо від початку до кінця.
