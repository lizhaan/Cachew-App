# Cachew: ТЗ для Claude Code (версія 2)

## Що змінилось у версії 2 (прочитай першим)

Версія 2 замінює попереднє ТЗ. Якщо код уже зроблено за версією 1, переробляй його за цим файлом. Ось що змінилось:

- **Маскота в інтерфейсі звати Penny** («Penny's den», «Penny levelled up»). Правило «писати Cachew замість Penny» скасовано.
- **Валюта всюди — «cashews».** Слів «nuts» і «горіхи» в інтерфейсі немає. На старих макетах «+15 nuts» → у коді «+15 cashews».
- **Екран рішення (15) замінено.** Замість «Add to waiting list / Use a heart / Buy it anyway» тепер «Just look, save, don't buy» / «I need something specific» / велика кнопка «Close <магазин>». «Buy it anyway» і сердечка на вході більше немає.
- **Форму «What did you want?» прибрано.** Після вибору людина повертається в магазин на сесію 10 хв: пігулка з таймером, кружечок Пенні, шторка на 5-й хвилині. Річ додається тільки через «Поділитися».
- **Вікно тиші 15 хв замінює сесія 10 хв** (див. етап 3).
- **За кожну річ, збережену через «Поділитися», +15 cashews** (раніше за Share нічого не давали).
- **Нічний щит — повний блок** магазинів у вибрані години, без режимів Soft/Strict. За 2 години до початку і до кінця щита розклад не можна змінити чи вимкнути.
- **Вердикт «Still want it?»:** Let it go / Buy it, I waited / I already bought it. Сердечко потрібне лише для того, щоб купити річ зі списку очікування до кінця таймера.
- **Рівні рахуються від cashews у запасі**, а не від суми «kept».
- **Головна:** квестів дня немає. Натомість ціль заощаджень (наприклад, Tokyo $900) і картка «Penny's winter stash».
- **Stats рахується з реальних даних**, а не статично.
- **Нові скріни лежать у design-v2/.** Де вони розходяться зі старими макетами в design/01_screens, правильні design-v2.

## Продукт

Cachew — Android-застосунок для людей з імпульсивними покупками (особливо з СДУГ). Коли людина відкриває обраний магазин, Cachew показує поверх нього паузу на 10 секунд, ставить 2 питання і пропонує план: тільки подивитися й зберегти річ замість покупки, купити щось конкретне або закрити магазин. На все дається 10 хвилин. Збережена річ чекає у списку очікування 24/48/72 год, потім приходить нагадування (лише вдень) з питанням «Still want it?». Маскот — білка Пенні: за кожну стриману покупку вона отримує cashews у свій зимовий запас і росте в рівнях.

Це демо для захисту. Під час розробки я ставлю його на свій телефон через Android Studio. Результат — APK-файл, який будь-хто може завантажити (за посиланням з GitHub Releases або з Telegram) і встановити на свій Android-телефон як звичайний застосунок, без Android Studio і без кабелю. Публікація в Google Play зараз НЕ мета.

## Стек і правила коду

- Kotlin, Jetpack Compose, Material3. minSdk 26, target/compileSdk — найновіші стабільні. Kotlin DSL у Gradle, version catalog (libs.versions.toml).
- Package `app.cachew`.
- Навігація: navigation-compose. Дані: один клас-репозиторій `Store` поверх SharedPreferences + JSON (org.json або kotlinx.serialization). Room і DI не потрібні.
- Дозволені бібліотеки: navigation-compose, work-runtime-ktx (нагадування), coil-compose (фото товарів), jsoup (розбір сторінки товару), kotlinx-coroutines, kotlinx-serialization. Інші — спершу запитай.
- Структура пакетів: ui/theme, ui/components, ui/screens/<екран>, data, pause, session, share, service, reminders.
- Тексти в інтерфейсі англійською (ринок — США). Тримай їх у strings.xml. Коментарі в коді англійською.
- Усі числа правил тримай в одному файлі `data/Rules.kt`: пауза 10 с, сесія 10 хв, перевірка на 5-й хвилині, +15 / +5 cashews, ліміт +5 на день, пороги рівнів, 2 години блокування розкладу щита, час очікування за замовчуванням.
- Репозиторій GitHub приватний. .gitignore для Android обов'язковий: без build/, .gradle/, local.properties, .idea/, *.jks, keystore.properties.

## Ігрова механіка (довідка для всіх етапів)

**Cashews** — єдина валюта. Не витрачаються: запас лише росте і визначає рівень Пенні.

| Дія | Cashews |
|---|---|
| Зберегла річ через «Поділитися» | +15 за кожну |
| «Close <магазин>» на екрані рішення або «I'm done · close <магазин>» на шторці | +5 (не більше 3 разів на день) |
| Let it go | +1 за кожен долар ціни |
| Невикористане сердечко 1-го числа | +50 за кожне |
| Стрік 7 / 30 днів | +50 / +200 |

**Рівні** (за cashews у запасі): 1 Kit — 0, 2 Forager — 50 (winter scarf), 3 Keeper — 150 (warm hat), 4 Stasher — 400 (flashlight for the den), 5 Winter-ready — 1000 (tree-hollow house). Рівень тільки росте.

**Сердечка:** 3 на місяць, поновлюються 1-го числа. Єдине застосування — купити річ зі списку очікування до кінця таймера: стрік зберігається, статус «bought with a heart». На вході в магазин і вночі сердечка не діють.

**Стрік** («Days in a row without an impulse buy»): +1 за кожен календарний день без «I already bought it», навіть якщо пауз не було. «I already bought it» обнуляє. Пропущені дні не обнуляють.

**Ціль заощаджень:** назва і сума (наприклад, Tokyo $900). Кожен Let it go додає ціну речі в доларах. Коли сума досягнута, Пенні святкує (поза love) і пропонує нову ціль. Досягнуті цілі видно в Me.

**Нічні години** = вікно нічного щита (за замовчуванням 23:00–07:00). Якщо щит вимкнено, тихі години для нагадувань 22:00–09:00.

Нового не створюй: попроси в мене посилання, потім `git remote add origin <посилання>`, `git branch -M main`, `git push -u origin main`. Якщо push просить увійти, зупинись і скажи мені: вхід я пройду сама у вікні браузера.
- Ми на Windows: збирай через gradlew.bat. Якщо телефон підключено (`adb devices`), після збірки став застосунок через `gradlew.bat installDebug`.
- Тема з design/04_android/Theme.kt, шрифт Inter, іконка застосунку, базові компоненти: фон день/ніч, PrimaryButton (фіолетовий градієнт), SecondaryButton (повнорозмірна, як GlassCard), GlassCard, Penny(image, size).
- Екран 08 «Where do impulse buys find you?». Сітка плиток 3 в ряд: літера на кольоровому квадраті + назва. Мультивибір, кнопка «Continue · N apps».
- Рекомендовані магазини у data/ShopApps.kt: назва, package name, колір. Порядок: Amazon, Shein, Temu, Sephora, Etsy, eBay, Walmart, Zara, Rozetka, Prom, OLX (в усіх збірках: APK ставитимуть і в Україні). Chrome — лише в debug-збірці, як тестовий «магазин». TikTok не додаємо.
- Рекомендовані магазини, яких немає на телефоні, показуй приглушено з підписом «not installed», але дозволяй їх обрати.
- Будь-який застосунок. Остання плитка в сітці — «+ Other app». Вона відкриває список усіх встановлених застосунків: іконка + назва, пошук угорі, за алфавітом, без самого Cachew. Обрані застосунки додаються в сітку плитками зі справжньою іконкою, вже вибрані.
- Список бери через `PackageManager.queryIntentActivities` з ACTION_MAIN + CATEGORY_LAUNCHER; у маніфест додай `<queries>` з цим intent. QUERY_ALL_PACKAGES не використовуй.
- Збережи вибір у Store як список package name (і рекомендовані, і довільні).
- Цей самий екран вибору відкривається з Me → «Shops with a pause» (етап 6).
- Перевірка: застосунок відкривається, обрані магазини (зокрема довільний застосунок через «+ Other app») зберігаються після перезапуску.

### Етап 3. Питання, рішення, сесія 10 хв (екрани 14, design-v2/02–04)

- **14 Questions:** 4 плитки настрою (Tired, Bored, Stressed, Fine) + «Was it on your list?» Yes/No. «Continue» активна тільки тоді, коли є обидві відповіді.

  - **I need something specific** — мітка «10 min», підпис «Get it and go. Penny waits in the corner and peeks in once.» → сесія «specific».
  - **Close <Shop>** — мітка «+5», повнорозмірна кнопка (не дрібний текст). → +5 cashews (ліміт 3 на день), домашній екран телефона.
- **Сесія (design-v2/03_session_overlay.png).** Магазин відкривається на 10 хв. Поверх нього два маленьких вікна, які не заважають скролити: пігулка зверху «🐿 9:12 left · just looking» (або «· specific») і кружечок Пенні (peek) справа з підказкою «Like something? Tap me». Тап по Пенні → коротка підказка, як зберегти річ: «Tap Share → Cachew». Вікна малюй з ShopWatchService як `TYPE_ACCESSIBILITY_OVERLAY` (окремий дозвіл «поверх інших застосунків» не потрібен).
  - Вийшла з магазину й повернулась, поки сесія триває, — паузи немає, таймер іде далі, вікна знову видно.
  - Коли 10 хв минули: якщо магазин відкритий, Cachew повертає на домашній екран телефона. Наступний вхід — знову пауза і питання.
  - Сесію «specific» Пенні перевіряє один раз: за 2 хв до кінця кружечок підстрибує з підказкою «2 minutes left».
  - Стан сесії (магазин, режим, час початку, чи була шторка) зберігай у Store, щоб він пережив перезапуск сервісу.

- Лог кожного входу в Store: час, магазин, відповіді, обрана дія, тривалість сесії. З нього рахується Stats.
- Перевірка: пройти всі три гілки; у «just looking» дочекатися шторки на 5-й хвилині; переконатися, що після 10 хв магазин закривається, а наступний вхід знову показує паузу.

### Етап 4. «Поділитися», лист очікування, нагадування, вердикт (екрани 16, 18, 19, 20, 21, 22, design-v2/05–07)

Після цього етапу пауза працює від початку до кінця.

- `ShareActivity` з intent-filter ACTION_SEND text/plain, дозвіл INTERNET.
- Із тексту Share дістань URL. Завантаж сторінку (IO, таймаут ~6 с, мобільний User-Agent) і розбери jsoup'ом: JSON-LD Product (name, image, offers.price) → og:title / og:image / product:price:amount → itemprop=price / `<title>` → запасний варіант: регулярний вираз по тексту Share ($, ₴, грн, €, пробіли в тисячах, кома як десятковий роздільник).
- Поки йде завантаження, показуй скелетон. Назва і ціна мають залишатися редагованими. Якщо ціну не знайдено, під полем ціни швидкі кнопки <$20 / $20–50 / $50–100 / $100+ (у суму йде середина діапазону, для $100+ — 100). Якщо сторінку не вдалося завантажити, тихо залишай те, що є, без помилок на екрані.
- Фото збережи у filesDir/thumbs/<id>.jpg і показуй через Coil. Якщо фото немає, показуй кольоровий квадрат з літерою.
- **16:** картка товару, «Wait for» 24h/48h/72h (за замовчуванням з налаштувань, стартово 48h), кнопка «Wait N hours».
- За кожну річ, додану через Share, +15 cashews. Share працює і без активної сесії.
- **Nice pause (design-v2/06):** «+15 cashews», Пенні love2, «Nice pause.», «Penny's holding your $X for N hours.» (без ціни — без суми), пігулка «<N>-day streak · +15 to the stash». Кнопка: вночі «Goodnight, Penny», вдень «Thanks, Penny». Якщо сесія триває — повертає в магазин, інакше на домашній екран телефона.
- У листі очікування назву і ціну товару можна відредагувати.
- **Нагадування (18):** WorkManager, unique work з id товару, на момент addedAt + N год. Тихі години: якщо цей момент припадає на нічні години, перенеси нагадування на їх кінець. Текст: «Your 48 hours are up» / «Still want the $64 knit sweater? Penny waited till morning to ask.» (останнє речення — лише якщо нагадування переносили). Канал reminders, іконка cashew. Дозвіл POST_NOTIFICATIONS запитуй під час першого додавання товару; якщо людина відмовила, нічого не ламається.
- Натискання на сповіщення відкриває 19 для цього товару. Якщо 7 днів немає відповіді, ще одне нагадування: «Let it go?».
- **19 «Still want it?»** (стиль з макета 19). Підказка з реальних даних: якщо товар додано вночі — «You added it at 23:43. Late-night wants often fade by morning.», інакше — «You've kept $X this month by waiting.». Три дії:
  - **Let it go · keep $X** → статус kept, сума додається до «saved this month» і до цілі, +1 cashew за долар → екран **Kept, not spent** (design-v2/07): «KEPT, NOT SPENT», «+$64», Пенні lie на купці cashews, «+64 cashews · Penny's stash: 99», «Penny levelled up · Level 2 · Forager · she got a winter scarf» (якщо рівень змінився, інакше «Penny's stash grew»), 3 пігулки: $ saved in <month> · day streak · hearts left, кнопка «Back to the den». ### Етап 5. Нічний щит (екран 10 без Soft/Strict)

- Налаштування: перемикач «Night shield on», час «from» і «to» через Material3 TimePicker (24 год). За замовчуванням 23:00 → 07:00. Вікно через північ має працювати. Однакові «from» і «to» не дозволяй.
- **У нічні години магазин повністю заблокований.** Замість паузи — екран блоку (нічний фон, Пенні sleep): «<Shop> opens at 07:00», «Penny's asleep. So is the sale.», одна кнопка «Close» → домашній екран телефона. Без питань і без варіантів. Сердечка блок не знімають.
- Якщо сесія триває на початку нічних годин, вона закінчується, а магазин закривається.
- **Правило 2 годин:** від «from − 2 год» до кінця нічних годин (наприклад, з 21:00 до 07:00) розклад не можна змінити і щит не можна вимкнути. У налаштуваннях рядок виглядає заблокованим з підписом «Locked until 07:00». Подовжити вікно або увімкнути щит можна завжди. Якщо людина змінює розклад у дозволений час, нове вікно діє з найближчої ночі.
- Нічні години визначають і тихі години нагадувань (етап 4).
- Скрізь, де видно час щита (головна, Me, блок), показуй реальні значення.
- Перевірка: ставлю щит на найближчу годину → відкриваю магазин → екран блоку; за 2 години до початку перевіряю, що розклад заблоковано.
- Після етапу: запис демо з телефона (див. сценарій нижче).

### Етап 8. APK для людей

- Налаштуй підпис release-збірки. Keystore (cachew-release.jks) і паролі зберігай поза репозиторієм: у keystore.properties у корені, і він у .gitignore. Згенеруй keystore командою keytool, а паролі попроси в мене. Поясни мені, що keystore і паролі треба зберегти: без них не вийде випустити оновлення, яке встановиться поверх старої версії.
- `gradlew.bat assembleRelease` → app/build/outputs/apk/release/app-release.apk. Перейменуй у Cachew-<versionName>.apk, наприклад через applicationVariants / outputFileName.
- Перед кожним новим APK збільшуй versionCode і versionName, інакше телефон не оновить застосунок поверх старого.
- Мінімізацію (R8) не вмикай, або перевір, що з нею нічого не ламається: Accessibility-сервіс, оверлеї сесії, Share і WorkManager.
- Опублікуй APK у GitHub Releases (`gh release create v<версія> Cachew-<версія>.apk --notes "..."`). Покажи мені посилання на завантаження.
- Додай у README розділ «Як встановити на телефон» простою мовою для людей без технічних знань:
  1. Завантажити .apk з посилання.
  2. Відкрити файл і дозволити встановлення з цього джерела (браузера або Telegram), коли телефон попросить.
  3. Відкрити Cachew і пройти онбординг.
  4. Увімкнути Cachew у Спеціальних можливостях. На Android 13+ для застосунків, встановлених з APK, перемикач спершу сірий («Обмежене налаштування»): Налаштування → Додатки → Cachew → ⋮ → «Дозволити обмежені налаштування», потім увімкнути ще раз.
  5. Дозволити сповіщення.
  6. Якщо Google Play Protect попереджає про невідомий застосунок, натиснути «Усе одно встановити». Це нормально для застосунків не з Play.
- Перевірка: видалити debug-версію з телефона, встановити APK, завантажений за посиланням, і пройти сценарій демо від початку до кінця.
